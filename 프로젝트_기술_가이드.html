기술의 역할과 사용 사례를 이해한 뒤, 당시 요구사항과 대안, 지금 다시 확인할 기준을 말해 보세요.

선택 이유를 직접 확인하지 못한 경우에는 기록된 구현을 먼저 설명하고, 개선은 제안으로 말합니다.

에이전트에 쓰이는 기술의 역할

LangChain은 모델·도구 구성, LangGraph는 상태와 분기, Harness는 실행 통제, MCP는 앱과 도구 서버 연결을 설명할 때 사용합니다.

모델이 도구와 인자를 제안하면 앱이 허용 범위를 확인하고 실행 결과를 돌려줍니다.

Tool Calling과 MCP는 같은 건가요?

답변 예시 Tool Calling은 모델이 도구 이름과 인자를 제안하는 방식이고, MCP는 앱과 도구 제공자를 연결하는 프로토콜입니다. MCP로 찾은 도구를 모델에게 호출 가능한 도구로 전달할 수 있습니다.

연결과 실행 통제는 별도입니다. 정책에 맞는 도구인지, 사용자에게 대상 리소스 권한이 있는지 서버에서 확인해야 합니다.
